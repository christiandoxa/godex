## Tagged behavior delta

The release requires no new flags or saved-session storage format. Its
observable changes include:

1. **Normal-screen terminal restoration.** Post-child cleanup selects the
   normal buffer via `DEC 1047` instead of repeating `DEC 1049`, which would
   restore an obsolete saved cursor and overwrite the native usage summary or
   plain-text session footer. Mouse, keyboard, paste, focus, and cursor cleanup
   must still occur without clearing the main screen or flushing queued input.
2. **Transient observer descriptor pressure.** File-descriptor exhaustion,
   SQLite busy/locked/cannot-open, and temporary interrupted/would-block reads
   during session observation must not kill a healthy foreground child or
   consume unread terminal failure evidence. Retry is bounded, observer-owned
   optional SQLite handles are released, and permanent identity errors remain
   explicit; ambiguous observation is never permission to replay.
3. **Exact native WebSocket idle timeout.** The native string
   `stream disconnected before completion: idle timeout waiting for websocket`
   with `codex_error_info=other` permits terminal transport recovery, subject
   to session ID, terminal-event, accepted-work, goal-state, cancellation,
   retry and no-duplication guards. This does not fix the upstream timeout.
4. **Hardening and internal reorganizations.** Tagged rustls 0.23.46 resolves
   four RustSec advisories in Prodex's Rust graph; Rust/Mojo extraction,
   diagnostic/provider changes, source-size splits and official Kiro 2.31.1
   release smoke pin are not automatically evidence of new Go requirements.
   Any changed observable provider or diagnostic behavior still needs tests.
